# RELATED_WORK — SafeFlipLab 相关研究核查记录

> 检索日期：2026-10-12（GMT+8）。检索方式：公开网络检索（arXiv / ACM / IEEE / ScienceDirect / MDPI）。
> 本文件只记录**已核验链接可访问**的条目；未逐字阅读全文的条目已标注。
> 本清单不构成完整综述，也不证明 SafeFlipLab 的原创性；任务书明确允许"未发现稳健反转"的零结果。

## 一、必选四个主题的对应文献

### 1. 反事实安全边际（Counterfactual Safety Margin）

- **Zanardi, A., Censi, A., Atzei, M., Di Lillo, L., Frazzoli, E.**
  *A Counterfactual Safety Margin Perspective on the Scoring of Autonomous Vehicles' Riskiness.*
  arXiv:2308.01050（2023，v4 2023-11-28）。链接：https://arxiv.org/abs/2308.01050
- **内容要点**：用反事实仿真（其他交通参与者"偏离正常行为"）量化自动驾驶风险；
  安全边际 = 导致碰撞所需的最小行为偏离。
- **与本项目的差异**：该工作扰动**其他道路使用者**的行为来度量风险，对象是未知策略的黑盒评估；
  SafeFlipLab 扰动的是**自车场景参数**（前车间距、自车初速），检验的是"更安全参数反而更高碰撞风险"
  的反直觉反转，并且限定在单一简化高速汇入仿真与单一冻结规则控制器内，不外推为真实道路风险。

### 2. 规划器可避免性 / 反事实分析（Planner Avoidability）

- **Nishiyama, D., Ynocente Castro, M., Maruyama, S., Shiroshita, S., Hamzaoui, K., Ouyang, Y., Rosman, G., DeCastro, J., Lee, K.-H., Gaidon, A.**
  *Discovering Avoidable Planner Failures of Autonomous Vehicles using Counterfactual Analysis in Behaviorally Diverse Simulation.*
  ITSC 2020；arXiv:2011.11991。链接：https://arxiv.org/abs/2011.11991
- **内容要点**：用行为多样的 RL 交通参与者生成碰撞场景，并用反事实重放区分
  "可避免"与"不可避免"失败，聚焦规划器缺陷。
- **与本项目的差异**：该工作通过替换/重优化规划器来判定可避免性，场景生成本身是搜索目标；
  SafeFlipLab 固定控制器与场景 schema，只做四条件配对对照（anchor / +gap / −speed / both），
  研究的是风险差的方向反转与交互，而不是规划器参数修复。

### 3. 变形测试（Metamorphic Testing）

- **Han, J. C., Zhou, Z. Q.** *Metamorphic Fuzz Testing of Autonomous Vehicles.*
  ICSEW'20（IEEE/ACM ICSE Workshops），pp. 380–385，2020。
  DOI：https://doi.org/10.1145/3387940.3392252
- **内容要点**：两阶段 metamorphic fuzz testing——先生成"不现实"场景检验鲁棒性，
  再用变形关系过滤误报；在百度 Apollo 上实测到 3.7% 真实失败率。
- **与本项目的差异**：MT 用于检验仿真/系统本身的有效性（oracle 问题）；
  SafeFlipLab 的"四条件 quartet"在形式上与 MR 相似（受控输入变换 + 输出关系检验），
  但我们的变换是场景参数的单因素/双因素干预，输出是真实仿真的碰撞二元变量，
  统计量为 paired delta 与交互项，不把仿真器缺陷作为研究对象。

- **补充（GPT 生成 MR 的仿真器测试）**：*Enhancing autonomous driving simulations:
  A hybrid metamorphic testing framework with metamorphic relations generated by GPT.*
  Journal of Systems and Software（ScienceDirect），2025。
  链接：https://www.sciencedirect.com/science/article/pii/S0950584925001673
  （摘要级核验：在 CARLA 中发现 4 个仿真器缺陷；说明"仿真器本身可能出错"，
  因此 SafeFlipLab 固定 HighwayEnv 1.10.2 + cornercaselab 0.3.0 接口并记录版本指纹。）

### 4. 仿真鲁棒性 / 安全关键场景搜索（Simulation Robustness）

- **Pan, D., Lu, B., Zhou, X., Mao, Y., Cao, L.** *Constraint- and Risk-Driven Search for
  Safety-Critical Scenarios in Autonomous Driving Simulation.* Vehicles, 8(8):188, 2026。
  DOI：https://doi.org/10.3390/vehicles8080188
  链接：https://www.mdpi.com/2624-8921/8/8/188/html
- **内容要点**：物理可达性 + 行为一致性 + 交通可行性约束构造合法场景空间，
  分层场景价值模型 + 风险反馈概率搜索；1000 次评估预算下发现率从 0.68% 提升到 49.62%。
- **与本项目的差异**：该工作以"发现率"为目标做风险引导搜索；
  SafeFlipLab 的两种方法（WideExplore / VerifyFirst）比较的是**固定预算下提名质量
  与独立审计证据**，并且明确允许零结果；我们不优化发现率，也不使用其风险模型。

## 二、其他相关背景（非必选主题，摘自媒体核验）

- **Shalev-Shwartz, S., Shammah, S., Shashua, A.** *On a Formal Model of Safe and Scalable
  Self-driving Cars.* arXiv:1708.06374（2017）。链接：https://arxiv.org/abs/1708.06374
  —— RSS 责任敏感安全模型：safe longitudinal distance 的正式定义。
  与"增大前车间距应更安全"的直觉直接相关；SafeFlipLab 在仿真中检验该直觉对规则控制器
  是否总成立（结果可能是反向或不成立）。
- **Koopman, P., Osyk, B., Weast, J.** *Autonomous Vehicles Meet the Physical World: RSS,
  Variability, Uncertainty, and Proving Safety.* SafeComp 2019（extended）。
  链接：https://users.ece.cmu.edu/~koopman/pubs/Koopman19_Safecomp_RSS.pdf
  —— RSS 在真实可变性下的局限；支持"安全边际参数并非单调安全"的研究动机。
- **DriveFuzz**（arXiv:2211.01829）与 **SafeBench**（arXiv:2206.09682）：
  自动驾驶模糊测试/基准平台（经 CornerCaseLab v0.3.0 docs/RELATED_WORK.md 转引，
  本机未再次逐字核验全文，标注为二手来源）。
- **Causality-driven Testing of Autonomous Driving Systems**（ACM TOSEM，DOI 10.1145/3635709）：
  因果模型引导的测试与固定预算比较（同上，二手转引）。

## 三、CornerCaseLab 与本项目的关系（复用边界）

- 上游项目：CornerCaseLab v0.3.0，https://github.com/lin-lab666/CornerCaseLab ，Apache-2.0，
  作者 吴昊霖（GitHub: lin-lab666）。**不在 PyPI 上**（已核验 `pypi.org/pypi/cornercaselab` 返回 Not Found），
  从 GitHub tag v0.3.0 安装。
- SafeFlipLab 通过**安装依赖**方式复用其公共接口（`Scenario` / `BOUNDS` / `simulator.evaluate` /
  `policy.action_for(policy="boundary")`），不复制、不改写其源码；场景 schema（merge-scenario-v1，
  六维）与 controller 均以其公开版本为准。
- SafeFlipLab 的新增内容是：四条件配对实验协议、两种预算分配方法、独立审计、配对风险差统计。
  这些不是已验证的原创算法，也不声称优于任何已发表方法。

## 四、结论边界

- 以上文献表明：反事实/变形/约束搜索思想均非首次出现；SafeFlipLab 不声称"全球首创"。
- 所有结果只针对简化仿真模型中的规则控制器，不构成真实道路安全结论。
