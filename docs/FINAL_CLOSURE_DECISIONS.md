## 1. 逐项决策、理由与边界

### P1 — MDE 的定位：**规划示例，不是批准**

- **决策**：把 **MDE = 0.10 s** 记录为**未来样本量规划的示例输入**。
  在该示例下，按冻结的推导程序（α = 0.05 经 Holm 最坏情况校正 ⇒ 每对比 0.0125、族 = 4；
  power = 0.80）需要 **59 个锚 / 708 episode**（取四个对比的最大值）。
- **理由**：
  1. 样本量**必须**由一个 MDE 才能确定，而 MDE 是**科研价值判断**（「多小的效应才值得关心」），
     不是工程参数；
  2. 负责人已明确「MDE=0.10 秒**仅作为未来样本量规划示例**，不是正式实验批准」；
  3. 因此本项目**只记录推导**，**不冻结样本量**、**不启动任何运行**。
- **不意味着**：不意味着已经批准 708 次（或任何次数）仿真；不意味着 0.10 s 是项目的目标效应量；
  不意味着可以据此创建 V03 获取预算。
- **附注（防止误读）**：18 个锚在**最灵敏**的对比（`Δboth`）上只能检出 **0.0837 s**；
  最迟钝者（`i_lin`）为 **0.180 s**。因此「n=18 能检出 0.084 s」是**上限能力**的表述，
  **不是**「所有对比都能检出 0.084 s」。

### P2 — V02 的定位：**探索性/描述性研究，结题**

- **决策**：V02 **以「完整的探索性、描述性研究」结题**。所有区间均为**描述性**；
  **不产出 p 值**、**不做 FWER 控制**、**不作任何显著性声明**。
- **理由**：
  1. sign-flip / max-T 的抽样假设 **A/B/C 均未被证明**（锚非随机抽取；四条件不可随机重排；
     扰动可交换性未证），而**系统无权自行批准**这些假设（`v02lab/stats_anchor.py` 强制门控）；
  2. 设计为**事后性**（整体受 V01 pilot 启发），且**未做外部预注册**，
     只有配置冻结（SHA-256）可作为时间证据；
  3. 在此前提下，**唯一诚实的定位**是估计性/探索性。
- **不意味着**：不意味着 V02 的结果「无效」或「无价值」——其**方法学装置**
  （连续终点 + 锚内扰动 + 预算会计 + 度量对拍）是可复现的工程事实；
  也不意味着未来不能做确证性研究（那需要新的独立数据与新协议）。

### P3 — 外部同行评审：**可选未来工作，不阻塞结题**

- **决策**：**外部**同行评审保持 **NOT DONE**，并明确列为**未来可选工作**；
  **不阻塞**本次探索性研究结题。
- **理由**：本轮已完成**内部独立对抗性复核**（代码/统计 + 科研方法，见 `docs/REVIEW_RESPONSE.md`）
  与**全量独立复算**（`docs/V12_INDEPENDENT_RECOMPUTE_20261015.txt`，141 项断言全部通过）；
  外部评审属于**新的资源与流程**，超出当前授权，且不影响探索性结论的成立。
- **不意味着**：**不得**把本项目表述为「已通过外部评审」或「已预注册」。

### P4 — 新增真实仿真：**拒绝**

- **决策**：**不授权**任何新增真实仿真，包括「用一小轮技术性采样加强方差估计」。
- **理由**：
  1. 授权预算已用满（V01 smoke 24 / pilot 240；V02 smoke 24 / pilot 240），
     且**不创建 V03**、**不以新版本重置预算**；
  2. 18 个锚的方差估计**确实不可靠**，这已被**明确写入局限**，而不是用新预算去"修饰"它；
  3. 在无确证性检验定位的前提下，加强方差**不改变**任何结论的性质。
- **不意味着**：不意味着方差估计问题已解决；恰恰相反，它保持为**未解决的局限**（见 §2）。

### P5 — 正式主种子：**不适用**

- **决策**：**不批准**任何正式主种子集合。
- **理由**：V01 formal 已 **NO-GO**；V02 **没有 formal 入口**，且负责人明确不启动 formal。
  既然不会运行，批准种子集合没有意义，反而可能被误读为「formal 已就绪」。
- **不意味着**：不意味着未来不能设计正式研究；但**必须先有**新的独立协议与新的授权预算。

### P6 — D4/D5/D6：**归档，不追认**

- **决策**：V01 遗留的 **D4/D5/D6** 保持 **PROPOSED** 状态并**归档**；
  **不追认为已批准**；本轮的结题决策**不**使它们生效。
- **理由**：负责人本授权再次确认「历史 D4/D5/D6 归档，不追认批准」；
  且「自主执行」不能作为追认既有未批准提案的理由。
- **不意味着**：不意味着 D4/D5/D6 是错误的；只意味着它们**从未获得授权**。

### P7 — 终点结构与不一致证据：**保留**

- **决策**：
  1. **M1（最小前向 TTC）**为**唯一的主要描述性终点**；
  2. **M2（低 TTC 步占比）**为**辅助指标**，**不作主推断**；
  3. **保留**两者在 `Δgap` 上的**方向不一致**，并在报告与论文中**显式并列**；
  4. **禁止**通过删除终点、改阈值（如把 `τ_low` 从 1.0 s 上调/下调）或改口径来消除不一致。
- **理由**：该不一致是**代理量在分辨率极限处不稳健**的真实证据，
  对读者理解「单一连续代理量不足以支撑安全结论」有直接价值。
  隐藏它等于**改写证据以适应结论**，被明确禁止。
- **不意味着**：不意味着 M2 与 M1 冲突到无法分析——两者的区间**都跨 0**，
  因此**都不可判定**；不一致本身**不是**反转证据。
