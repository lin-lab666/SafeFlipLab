## 3. 样本量（由 pilot 的 18 个锚推导；**尚未冻结**）

锚级 SD（真实 pilot 数据）：`Δgap 0.144`、`Δspeed 0.203`、`Δboth 0.106`、`I_lin 0.229` s。

`n = 18` 时，在 α = 0.05（4 对比 Holm 最坏情况校正）、power = 0.80 下，
**最小可检出的 MDE ≈ 0.084 s** —— 这解释了为什么 pilot 观察到 0.003–0.033 s 的效应却无法判定。

| MDE (s) | 所需锚数 | 折合 episode（×3 reps ×4 条件） |
|---:|---:|---:|
| 0.05 | 235 | 2 820 |
| 0.10 | **59** | **708** |
| 0.15 | 27 | 324 |
| 0.20 | 15 | 180 |
| 0.30 | 7 | 84 |

**冻结正式样本量前必须做的事**（§5 阻塞项）：
1. **人工声明 MDE**（科研判断：多小的效应才值得关心）；
2. **加强方差估计**（18 个锚不够；需一小轮技术性采样，**需另行授权预算**）；
3. 若要求跨种子稳定性，episode 数再乘种子数。

## 4. 统计计划（拟冻结内容）

- 主族 = `{Δgap, Δspeed, Δboth, I_lin}`（4 个），**预注册、只检验一次方向、不择优**；
- 方向：`Δ > 0` 为直觉（更安全），`Δ < 0` 为反转；
- 多重性：**Holm 最坏情况**（保守且**无需**可交换性假设）；**不**把 max-T 随机化临界值
  用作主判据（其有效性依赖未证明的可交换性，见 D35）；
- 报告：点估计 + 锚级 cluster bootstrap 区间 + **锚级符号异质性**（负/正向锚数、
  剔除最大 3 正向锚的敏感性）+ `I_log` 的可定义比例与原因码 + 二元事件**描述性计数**；
- **禁止**：rule of three、episode 级独立、把描述性说成显著、把 M2 当主终点、
  用 audit 流估计 `E_pop`；
- 若正式数据仍显示锚级符号高度异质，**必须如实报告异质性**，不得只报聚合均值。
