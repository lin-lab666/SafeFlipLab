- **目的**：为"保留 V01 全部历史证据、另行设计 V02 预注册协议"提供完整、可审计的设计草案：
  研究假设、终点、尺度、有效随机扰动、四条件配对、独立审计、公平预算、锚级统计推断与
  技术 GO/NO-GO 门槛。
- **为什么需要 V02（基于真实证据）**：
  - V01 pilot 240 episodes 全部 `ego_collision = 0`，主指标（碰撞二元差 `delta_both`）**零方差**；

- **边界**：V02 只研究简化仿真中单一冻结规则控制器的行为，**不构成真实道路安全结论**，
  不声称全球首创、不声称优于任何已发表方法（含 CornerCaseLab）。V01 历史数据在 V02 中**只作
  管道验证与设计门槛输入**，**不得**当作 V02 的证据（避免事后选择，见 §13）。

## 2. 研究假设（H-R / H-I 分离，全部 PROPOSED）

### 2.0 符号与直觉方向（先验，来自机制而非试验符号）

对连续终点（主终点 M1 见 §3）：

- `Δgap  = M(10) − M(00)`（仅增大前车间距）；
- `Δspeed = M(01) − M(00)`（仅降低自车初速）；
- `Δboth = M(11) − M(00)`（两者同时）；
- `I_lin = M(11) − M(10) − M(01) + M(00) = Δboth − Δgap − Δspeed`（线性尺度交互）。

其中 M(·) 越大代表越安全（M1 为最小前向 TTC）。**先验直觉方向**（由机制推导，不由 pilot 符号决定）：
增大前车间距、降低自车初速、或两者同时，都应**提高**安全裕度，即
`Δgap > 0`、`Δspeed > 0`、`Δboth > 0`。

### 2.1 H-R：安全反转（方向性假设，单因素 + 联合）

> **定义**：安全反转 = 一个**先验被判为更安全**的干预，在观测中**朝相反方向**改变安全裕度。

- **H-R1a**：`Δgap < 0`（增大前车间距反而降低最少前向 TTC）。
- **H-R1b**：`Δspeed < 0`（降低自车初速反而降低最少前向 TTC）。
- **H-R1c**：`Δboth < 0`（联合干预反而降低最少前向 TTC）。
- **效应量（方向性）**：对每个对比 `k ∈ {gap, speed, both}`，报告锚级平均配对差
  `Ê[Δ_k]`（单位：秒），及其**锚级 cluster bootstrap 置信区间**；反转的**可判定形式**为
  该区间的**非直觉一侧**严格越过 0（见 §2.5 "稳定反转"的判定门槛）。
- 说明：H-R 是**单对比、方向性**主张；它与"交互是否为 0"**逻辑独立**（见 §2.6）。

### 2.2 H-I：二因素非加性交互

> **定义**：非加性交互 = 联合干预的效应**不等于**两单因素效应之和。

- **H-I-lin（主尺度，线性/差尺度）**：`I_lin ≠ 0`（双侧）。
  效应量 = `I_lin`（秒）；`I_lin > 0` 表示**超可加**（联合比相加更安全），
  `I_lin < 0` 表示**次可加**（联合比相加更不安全）。
- **H-I-log（次尺度，比值/对数尺度；次要）**：`I_log = log M(11) − log M(10) − log M(01) + log M(00) ≠ 0`。
  效应量 = `I_log`（无量纲）。**必须显式声明尺度**：加法性依赖尺度，`I_lin = 0` 与 `I_log = 0`
  是**不同**的问题（"联合是否等于两效应之和" vs "联合比值是否等于两比值之积"）。
- **`I_log` 的定义域与退化处理（重要，PROPOSED）**：`I_log` **仅当四个对比量均为有限且严格 > 0 时才有定义**。
  否则**返回未定义**并给**原因码**，**绝不用**任意替换值（如 `log(max(v, ε))`）冒充：
  - `ZERO_TTC`：任一 `M(·) = 0`（最小前向 TTC 为 0）⇒ `log 0 = −∞`，**未定义**；
  - `CENSORED_INFINITY`：任一 `M(·)` 为右截断（无闭合速度 / 全程无候选，见 §3.4 Layer 1–2）⇒ `log ∞ = +∞`，**未定义**；
  - `MISSING`：任一 `M(·)` 缺失（技术失败 / 配对缺失，见 §3.4）⇒ **未定义**；
  - **可选（PROPOSED，须显式提供地板值参数，不得默认）**：若人工批准，可另报"**地板对数**"版本
    `I_log^c = log max(M(·), φ) − …`（φ = 预注册地板，如 φ = τ_cap 的倒数或某秒数），
    但仍须**保留原因码**、并**同时**报告未定义比例；地板版本**不得**作主结论。
  - 报告须给出 `I_log` 的**可定义比例**（四个量均有限的锚占比）。
- **预注册规则**：**主交互尺度 = 线性（`I_lin`）**；`I_log` 为次要稳健性尺度，一并预注册、一并报告，
  但**不**用于主结论。若审查者要求以比值尺度为主，须在数据前改定并在 `DECISION_LOG` 留痕。
- 对二元次终点 B1，交互定义为**风险差尺度** `Y11 − Y10 − Y01 + Y00`（沿用 `stats.quartet_metrics`），
  并另报**风险比/对数优势尺度**；低事件率下风险差尺度近乎退化，故 B1 交互**仅作探索性**。

### 2.4 H2：方法比较（**辅助研究问题**，PROPOSED）

- **H2（辅助）**：等预算下，VerifyFirst 与 WideExplore 在独立审计中的**提名质量**

- **定位**：H2 **不再是主假设**。理由：
  1. V01 pilot 显示提名信号**零方差**，方法对比**无已证实的判别力**；

- H2 的检验**预注册但非确证性**，报告时须显式标注 **exploratory / auxiliary**，且**不得**与主族

### 2.5 "稳定反转"的判定门槛（防止把单个样本称作反转）

单个"反转对"（`Y00=0, Y11=1`）**永不**称为稳定反转（沿用 `stats.py` 注释）。反转的可判定需**同时**满足：

1. 锚级平均配对差的**点估计**朝非直觉方向（`< 0`）；
2. 其**预注册置信区间**的**非直觉一侧**严格越 0（等价于单侧检验在预注册 α 下显著）；
3. 满足预注册的**最小锚数** `n_min`（由技术 pilot 的有效样本量确定，PROPOSED 起点见 §7）；
4. 通过**阴性对照 G5**（管道未被污染）。
以上三条（1–3）为 **PROPOSED 硬判据**；任一不满足即**只作估计、不作反转宣称**。

### 2.6 反转 × 交互的 2×2 关系（避免混淆）

| | `I_lin ≈ 0`（可加） | `I_lin ≠ 0`（非加性） |
|---|---|---|
| **两单因素均朝直觉方向（`Δgap>0, Δspeed>0`，无单因素反转）** | 常规：联合 = 两效应之和；**无反转** | (a) **联合仍朝直觉方向**（超/次可加，无反转）；(b) **单因素不反转、但联合反转**：`Δboth < 0` 而 `Δgap>0, Δspeed>0` ⇒ 强次可加，`I_lin = Δboth − Δgap − Δspeed < 0` |
| **至少一单因素反转（`Δgap<0` 或 `Δspeed<0`）** | **单因素反转**：方向反转但效应可加 | **反转且非加性**：最复杂情形 |

> **要点（v2 修正）**：
> 1. `I_lin ≠ 0` **本身既不蕴含也不等价于**安全反转（v1 将二者等同，本版纠正）；
> 2. **必须**覆盖右上格 (b) 这一情形——**两个单因素各自按直觉改善，联合干预却反转**（`Δboth<0`）：
>    它说明"**联合反转**"是一个与"**单因素反转**"**独立**的命题，H-R1c（联合反转）**不能**由
>    H-R1a/H-R1b（单因素）推出，必须**单独**检验；强次可加（`I_lin` 显著为负）是其**充分条件之一**，
>    但 `Δboth<0` 亦可由其它组合产生，故 H-R1c 与 H-I-lin **分别**预注册、**分别**报告。

### 2.7 零结果可接受

若 H-R/H-I/H2 不被支持，即为有效零结果；**不得**在事后更换终点、尺度或方向以求显著。

## 3. 实验终点与预注册（单一主终点 + 关键次要，PROPOSED）

### 3.1 层的定义

- **episode**：一次四条件之一。→ **quartet**：同一 (anchor, repetition, sim_seed) 的四条件。→
  **anchor**：独立单元（见 §8.1）。

### 3.2 为什么是"单一主终点 + 关键次要"，而不是 co-primary（原 M1/M2）

v1 将 M1（最小前向 TTC）与 M2（低于阈值时间占比）设为 **co-primary**。本版改为
**单一主终点 M1 + 关键次要 M2**，理由：

1. **co-primary 的代价**：co-primary 要么要求**两者同时显著**（交集-联合，功效按两者较弱者计，
   样本量显著增大），要么放宽为"任一显著"（**α 膨胀**，需额外校正）。两者都劣于单主终点。
2. **信息重叠**：M1 与 M2 是**同一 TTC 轨迹的单调函数**，高度相关，co-primary 换来的**独立信息有限**，
   却付出多重性/功效代价。
3. **机制对齐**：干预直接作用于前向闭合几何，**min-TTC 是该闭合的诊断量**，且为上游冻结指标
   `metrics.longitudinal_ttc` 的逐 episode 最小值 ⇒ 事后选择风险最低，宜作**唯一主终点**。
4. **M2 的互补价值**是"**持续性**"（单点极值 vs 持续暴露），属**不同**问题 ⇒ 定位为**关键次要**，
   经**固定序列门控**（fixed-sequence gatekeeping，M1 显著后方检验 M2，**不耗 α**）。

|---|---|---|---|
| 连续 | **主终点 M1：最小前向 TTC** | 冻结上游 `metrics.longitudinal_ttc` 的逐 episode 最小值，按 §3.4 **三层规则**处理缺失/截断 | **唯一主** |
| 连续 | **关键次要 M2：低于阈值时间占比** | 前向 TTC < τ 的 policy step 比例（τ 预注册，如 1.0 s；暴露不足见 §3.4） | **关键次要（门控）** |
| 连续 | 次要 S1：最小前向间距 gap | episode 最小前车间距（同 §3.4 三层） | 次 |
| 连续 | 次要 S2：reward_sum | 冻结奖励 | 次 |
| 二元 | 次终点 B1：ego_collision | 冻结主碰撞指标 | 次（仅 G3 通过时检验） |
| 诊断 | D1：轨迹闭合散度步 / 首差步 | 验证 H4 与种子语义 | 诊断 |
| 诊断 | D2：干预生效校验 | 条件化场景字段确按 Δg/Δv 改变 | 诊断 |
| 诊断 | D3：截断/缺失计数 | 三层各态计数与占比（§3.4） | 诊断 |

### 3.4 M1 的三层处理（**时间步状态 / episode 汇总 / 终止状态 分离**；PROPOSED）

> v1 把"缺失/无候选/提前终止"混在一张五态表里，语义纠缠。v2 **分离为三个正交层**，
> 并在代码中以**独立纯函数**实现（`v02lab/ttc_state.py`）。三层**互不替代**：Layer 1 逐 step，
> Layer 2 汇总一个 episode，Layer 3 独立记录终止原因。

#### Layer 1 — 逐 policy step 状态（`StepTTCCState`）

对每个 policy step（5 Hz，最多 125 步）按上游 `metrics.longitudinal_ttc` 语义分类。候选车定义：
**前方**（`ox > x`）且**横向重叠**（`|oy − y| ≤ 2.0 m`）；`gap = ox − x − 5.0`（扣 5 m 车长），
`closing = vx − ovx`。

| 记号 | 状态 | 触发条件 | 逐 step 值 |
|---|---|---|---|
| **L1a** | `NORMAL_CLOSING` | 候选存在且 `closing > 0` | `gap/closing`（`gap ≤ 0 → 0.0`），有限 |
| **L1b** | `NO_CLOSING` | 候选存在但 `closing ≤ 0`（不接近） | 常规 TTC = **+∞**（**不得**记有限值） |
| **L1c** | `NO_CANDIDATE` | 该步无符合"前方+横向重叠"的候选 | 上游 `None`（**`None ≠ 安全`，`None ≠ 0.0`**） |

#### Layer 2 — episode 汇总（`EpisodeTTCCategory`）

把一个 episode 的逐 step 状态汇总为**四类之一**（互斥），并记录**暴露量**与**各状态计数**：

| 记号 | 汇总类别 | 触发条件 | 主分析取值（PROPOSED） |
|---|---|---|---|
| **L2a** | `FINITE` | 至少一个 L1a（有有限闭合值） | `min`（**仅在 L1a 有限步上**取）；同时报**截断步数**（L1b/L1c 计数） |
| **L2b** | `CENSORED` | 无 L1a，但至少一个 L1b | **右截断**于预注册上限 `τ_cap`，置**截断标记** |
| **L2c** | `NO_CANDIDATE` | 全部 step 均为 L1c | **构造上先验安全**的独立类别：主分析按 **(b) 赋 `τ_cap` + 标记**；并给 **(a) 剔除该 episode** 的敏感性分析 |
| **L2d** | `MISSING` | 技术失败 / 无有效 step（见 Layer 3） | **剔除**该 episode；**仍计费**；**绝不**以 0 或 ∞ 填充 |

**暴露量**：每条记录报 `n_steps_observed`、`n_steps_normal/closing_free/no_candidate`、是否触达 horizon。
M2 的分母 = **有效暴露 step 数**，**不是**固定 125。

> **L1b/L1c 语义区分（关键）**：`NO_CLOSING` = "有车但**不接近**"（缺口不会缩小，TTC 概念上为 +∞）；
> `NO_CANDIDATE` = "**根本无前车**"（上游 `None`）。二者在 Layer 2 归入**不同类别**（L2b vs L2c），
> **不得**合并、**不得**都当 0。

#### Layer 3 — 终止状态（`TerminationClass`，与 Layer 2 正交）

| 记号 | 终止类别 | 触发 | 对 Layer 2 的影响 |
|---|---|---|---|
| **L3a** | `HORIZON_REACHED` | 正常跑到 horizon | 正常汇总 |
| **L3b** | `TERMINAL_EVENT` | 碰撞 / 越界 / 到达目标等**真实终态** | **有效**：Layer 2 取**已观测 step** 汇总，并记终态原因 |
| **L3c** | `TECHNICAL_FAILURE` | `error` / `interrupted` | **强制 Layer 2 = `MISSING`** |

#### 配对缺失（`PairMissingness`）

对同一 (anchor, repetition) 的四条件，定义 quartet 配对对比的可用性：

- **`PAIR_MISSING`**：四个条件中**任一**为 L2d（MISSING）⇒ 该 quartet 的**全部对比**未定义，
  该 repetition **从 anchor 汇总剔除**（但计费、计数）；**不得**用其余条件"补位"。
- **`CENSORING_AFFECTED`**：无 MISSING，但至少一个条件为 L2b/L2c ⇒ 对比**存在**但受截断影响，
  须**单独标记**并计入 `I_log` 的 `CENSORED_INFINITY` 原因码（§2.2）。
- **`OK`**：四条件均为 L2a（或按 (b) 处理后的等价有限值且无截断标记）。

**通用规则**：

- **不得**对缺失做任何隐式插补；所有插补（如 `τ_cap`）必须**预注册**并带**标记**。
- **截断比例门槛**：`(L2b+L2c)` 占比**必须**在报告显式给出；超过预注册上限 → 触发 **G10**（§10）。
- **anchor 级 M1** = 仅用**可用（非 L2d、非 PAIR_MISSING）** repetition 的均值；若某 anchor 可用 repetition
  低于预注册下限，则该 anchor 从主分析剔除并计数（`D3`）。

### 3.5 配对效应量（连续尺度）

对每个 quartet 定义配对差（以 00 为对照）：`Δgap`、`Δspeed`、`Δboth`、`I_lin`（符号见 §2.0）。
**anchor 级效应** = 该锚内所有**可用 repetition** 的对应配对差的均值（先在 (anchor, repetition)
内配对，再对 repetition 求均值）。**主估计量 = anchor 级 ATE**（每个对比各一）。

### 3.6 主终点与效应量的对应（预注册）

| 假设 | 对比 | 尺度 | 先验方向 |
|---|---|---|---|
| H-R1a | `Δgap` | 秒 | `> 0` 直觉；`< 0` 即反转 |
| H-R1b | `Δspeed` | 秒 | 同上 |
| H-R1c | `Δboth` | 秒 | 同上 |
| H-I-lin（主交互） | `I_lin` | 秒 | 双侧 `≠ 0` |
| H-I-log（次交互） | `I_log` | 无量纲 | 双侧 `≠ 0`（次要） |

### 3.7 终点选择的诚实性声明

M1 是**基于机制**提出的（干预直接作用于前向闭合几何），**不是**因为 pilot 探索性分析出现负 ΔTTC
才挑选。；但**本设计的整体构思确受 pilot 探索结果启发**——这一点在 §13 显式披露，
并给出事后选择风险的控制措施。若审查者仍认为风险不可接受，退路为**放弃假设检验、只作估计**（§8.6）。

## 4. 有效的随机扰动（P1–P4，核心修复，PROPOSED）

> 目的：让**锚内 repetition 真正重采样 ego–lead 交互**。V01 退化（评审 §3.3）的根因是
> `DELTA` 只作用于 ramp，而 lead 处于自由流使加速度与 `DELTA` 无关。V02 必须**在 ego–lead
> 闭合上引入可验证的随机性**。
>
> **通用约束（四个 P 共同遵守）**：
> (i) **四条件共享同一次扰动抽样**（配对不变）；
> (ii) 扰动**不依赖 condition**（否则扰动与干预混杂）；
> (iii) 抽样须落在上游 `BOUNDS` 内，**越界即拒绝重采，不 clip**；
> (iv) 每个 P 的分布参数**预注册**并在任何数据前冻结；
> (v) 扰动使估计目标变为**对扰动分布的锚级平均效应（population-averaged）**——须如实声明。

### 4.1 P1 — lead 初速/目标速度抖动（**修复 V01 根因的关键**）

- **随机化对象**：lead 的初速与/或 IDM 目标速度 `v0`。
- **分布（PROPOSED）**：以锚名义值为中心，`v_lead ~ U(v_nom − δ₁, v_nom + δ₁)`（δ₁ 预注册；
  或截断正态、须先定）。确保 `v_lead ≠ v₀` 或 lead 前方存在更慢车，使
  `COMFORT_ACC_MAX·(1 − (v/v₀)^DELTA)` **依赖 `DELTA`** ⇒ lead 轨迹随 repetition 变化。
- **理由**：直接消除"lead 处于自由流 ⇒ 轨迹与种子无关"（评审 §3.3）这一退化。
- **可证伪点**：G4 检查 lead 轨迹/闭合序列在 repetition 间**确实变化**，且 min-TTC **不再**跨
  repetition 逐位相同。

### 4.2 P2 — 初始 front_gap 抖动

- **随机化对象**：anchor 的名义初始前车间距。
- **分布（PROPOSED）**：`gap₀ ~ U(gap_nom − δ₂, gap_nom + δ₂)`，且须保证**四条件**（含 `+Δg`）
  均在上游界内，否则拒绝重采。
- **理由**：把"单点几何"变为"几何分布"，检验几何效应的鲁棒性。
- **可证伪点**：G4 锚内方差 > 0。

### 4.3 P3 — lead 减速事件（使 TTC 有意义、使碰撞可能）

- **随机化对象**：lead 在预注册时刻 `t*`（或预注册的 `t*` 分布）施加**一次有界减速**。
- **分布（PROPOSED）**：以预注册概率 `p₃` 触发；减速幅度**受 IDM 舒适减速界约束**
  （`≤ COMFORT_DEC_MAX`），持续时长预注册。
- **理由**：V01 中 lead 恒自由流、gap 只增不减 ⇒ TTC 常被右截断、碰撞几乎不可能。
  **P3 是产生真实闭合、使 M1 有区分度、使 B1 可能发生的关键机制**。
- **诚实性要求**：P3 是四个 P 中**最"人工"**的一个，**必须**论证其物理合理性；
  **不得**为制造碰撞而调参。为此设 **G9**（§10）：减速在 IDM 舒适界内、碰撞率落在预注册
  合理性区间；若碰撞率被"调"到异常高 → **NO-GO**。
- **耦合**：同一 (anchor, repetition) 四条件共享同一 `t*` 与减速幅度。

### 4.4 P4 — ego 初速抖动

- **随机化对象**：anchor 的名义 ego 初速（**干预前**名义）。
- **分布（PROPOSED）**：`v_ego ~ U(v_nom − δ₄, v_nom + δ₄)`。
- **与干预的组合（须先定义，避免混杂）**：干预 `−Δv` 作用在**该 repetition 的 ego 名义初速**上，
  即 `v_ego(condition 01/11) = v_ego(draw) − Δv`；四条件共享同一 `v_ego(draw)`。
- **理由**：使初速条件分布化，检验速度效应的鲁棒性。

### 4.5 PROPOSED 组合与预算影响

- **组合：`P1 + P2 (+ P3)`** 为**主组合**；P4 作可选稳健性维（若预算允许）。
- 扰动维数直接影响技术 pilot 的方差估计与正式样本量（§7）。

### 4.6 可证伪的有效性前置检查（G4，详见 §10）

在正式 V02 之前，用**独立技术 pilot**（预算单列，§7）验证：

1. 锚内主终点方差**显著 > 0**（且 ≥ 预注册最小方差 `s²_min`，非仅"非零"）；
2. 轨迹/闭合序列随 repetition 变化，且 **ego 或 lead 轨迹首差步出现在 min-TTC 步之前**
   （复用 V01 的散度诊断，评审 §3.3）；
3. min-TTC **不再**跨 repetition 逐位相同（否定 V01 的种子不变性）。
若 G4 失败 → **NO-GO**：不得用"新鲜种子"充当独立证据。

## 5. 四条件配对设计（PROPOSED）

- 条件：`00`（原始 anchor）、`10`（仅 `front_gap += Δg`）、`01`（仅 `ego_speed −= Δv`）、
  `11`（两者同时）；**Δg、Δv 预注册且全 condition 位于上游 BOUNDS 内**（越界拒绝采样，不 clip）。
- 配对：同一 (anchor, repetition) 的四条件共享**同一扰动抽样**与**同一 `sim_seed`** ⇒ 条件间配对比较。
- **因子结构声明（重要）**：本设计是**固定的 2² 析因内设计**——`10/01/11` 是**结构性、角色固定**的

  （例如对前向闭合无关的维度施加等幅扰动）。阈值：若 placebo 效应超出容差 → 管道失效（G5）。
- 只采样四条件均在界内的 anchors（沿用 V01 generator 的拒绝采样语义）。

## 6. 独立审计与 H2 提名质量指标（PROPOSED）

### 6.1 审计的角色与隔离（沿用 v1）

- **提名先于审计**：提名在任何审计 episode 启动前冻结；审计结果**不得**回灌提名规则。
- **审计种子与 discovery 严格分离**（stream 标签进入种子派生，`seeds.sim_seed_for`）。
- **审计使用与 discovery 相同的扰动分布**（否则审计不可比）。
- **报告**：discovery 与 audit 分开报告（沿用 V01 §4）。

### 6.2 H2 的**提名质量指标**（预注册，须在数据前冻结；v2 修订）

> **v2 修订要点**：v1 的 Q1 以"越过风险阈值 η"为目标，与全文主问题（**干预导致安全裕度反转**）
> 不一致；且 Q3 regret 定义在"候选池"上，而候选池中**未提名锚根本未被审计**，无从观测。
> 本版把 H2 的提名目标**对齐到反转**，并显式处理 regret 的**不可观测**问题。

**H2 的提名目标（与主问题一致）**：方法应更擅长提名**干预会反转安全裕度**的锚。
定义锚级**审计反转指示** `R_a = 1{ Δboth^audit(a) < −δ_eq }`（`δ_eq` = 预注册等价/非劣余量；
`R_a` 在**审计流**上计算，四条件配对、同扰动分布）。

设某方法提名锚集 `π`（|π| = k）。审计流对每个提名锚给出新鲜种子 quartet ⇒ 锚级审计对比量。
**预注册指标**（全报，主指标 1 个）：

| 编号 | 指标 | 定义 | 角色 |
|---|---|---|---|
| **Q1** | **反转命中率 precision@k** | `π` 中**审计反转指示 `R_a = 1`** 的锚占比 = `(1/k)·Σ_{a∈π} R_a` | **主（H2 主指标）** |
| Q2 | 发现–审计秩相关 | discovery 与 audit 锚级 `Δboth` 的 Spearman ρ | 次（信号保真度） |
| Q3 | **提名集内受限后悔**（restricted regret） | `max_{a∈π} S_a − mean_{a∈π} S_a`（`S_a` = 锚级审计统计量，**仅在已审计的 `π` 内**） | 次（**仅 π 内可定义**） |
| Q4 | 反转存活性 | `π` 中 discovery 反转指示与 audit 反转指示**一致**的锚占比 | 次（复现性） |

- **Q1 阈值来源**：`δ_eq`（反转判定余量）须**预注册**、由机制/工程判据设定，
  **不得**取到使某方法恰好获胜。Q1 **不使用**任意"风险阈值 η"（v1 做法已废止）。
- **recall / 全池指标不可估**：`π` 之外候选锚**未被审计**，故**全池 recall、全池 precision、
  oracle（全池最优）均不可观测 ⇒ 一律标记 `NOT_ESTIMABLE`**，**不得**用 discovery 值冒充审计值。
- **Q3 的受限定义与不可估性**：v1 的"候选池内最优 − π 均值"**不可估**（需审计全池）。
  v2 只定义**π 内的受限后悔**（可算），并在报告中**显式声明**其**非全池 oracle regret**；
  若人工要求全池 regret，则须**另设审计全池的预算/设计**（属新设计，非本提案默认）。
- **诚实性**：全部指标须在数据前冻结；报告须给出 `k`、审计 quartet 数、每锚审计统计量的
  锚级不确定性，以及被标 `NOT_ESTIMABLE` 的项清单。
- **定位重申**：H2 为**辅助**研究问题（§2.4），报告标注 **exploratory**，**不**并入主族多重性校正，
  且**不得**以 Q1–Q4 的显著替代主结论。

## 7. 公平预算与样本量（PROPOSED）

### 7.1 等预算原则

- 每 `method × master_seed` 的 episode 预算**完全相等**；比较的是**分配方式**，不是预算量。
- 结构（PROPOSED 起点，最终数由设计分析确定）：
  - WideExplore：N_disc 个不同 anchor × 1 quartet（discovery）→ 提名 top-k →
    每提名 m 个全新 seed quartet（audit）；
  - VerifyFirst：stage-1 前 N1 个 anchor × 1 quartet → 冻结 Nsel 个 → 各追加 extra 个 quartet →
    从全部 stage-1 anchor 按冻结规则提名 top-k → audit 同 WideExplore。
- **所有已发起 episode（含失败/中断）计费，无免费重试**（沿用 V01 账本语义）。

### 7.2 **独立技术 pilot 预算**（单列，计入总预算，零 formal；PROPOSED 待批）

> 目的与正式阶段不同——**只用于**：(a) 验证扰动有效性（G4）、(b) **估计锚级方差以确定正式样本量**、
> (c) 验证 L-01 新账本（G7）、(d) 校准 P3 合理性（G9）。**不**用于方法比较、**不**作 V02 证据。

- **种子（v2 澄清：dev seed 冲突）**：V01 的 `DEV_SEED = 20261011` 是**单一**种子（V01 约定）。
  本文件 v1 写"仅用 dev seed（`20261011`）"，却又在 TP-2 用"2 dev seeds"——**二者冲突，此处澄清**：
  - V02 的**开发种子集**是一个**显式参数（列表）**，**不是**默认值；
  - **TP-1** 使用**恰一枚**开发种子 `[20261011]`（复用 V01 开发种子，**仅作 dev、永不 formal**）；
  - **TP-2** 使用**两枚**开发种子 `[20261011, <v02_dev_seed#1>]`，其中第二枚**当前为 `PROPOSED_UNSET`**，
    须由人工显式命名或批准一条**确定性派生**（如 `Sha256(["SafeFlipLab-v02","dev",i])`）后方可冻结；
    **在冻结前不得运行 TP-2**。
  - **声明**：复用 V01 开发种子**不违反** §13 的 V01 防火墙——因为 dev 运行**只作设计**、

  - **冻结要求**：开发种子**个数与取值**必须在**技术 pilot 前**冻结。

## 8. 锚级统计推断（**重设计，不默认标签可交换**，PROPOSED）

### 8.1 独立单元与聚类

- **独立单元 = anchor（场景）**。同一 anchor 的所有 repetition/条件视为**簇内相关**；
  估计与推断在 **anchor 层**进行（先簇内配对求差，再跨锚汇总）。
- **明确否定**：**不得**把 episode 当独立样本（评审 §2.3）；**不得**把 repetition 当作对 ego–lead
  的独立重采样（V02 的 P1–P4 使其**部分**成立，但仍以 anchor 为聚类单元，见 §8.3）。

### 8.2 估计与区间（不依赖交换性假设）

- 主估计量：anchor 级配对差均值 `Δgap`、`Δspeed`、`Δboth`、`I_lin`（及 `I_log`）。
- 区间：**锚级 cluster bootstrap**（对 anchor 有放回重采样，B 预注册如 10,000），报告偏差校正区间。
  **bootstrap 的有效性只依赖"anchor 是抽样单元"，不依赖条件标签交换性** ⇒ 与 §8.3 解耦。

### 8.3 假设检验：**禁止锚内置换条件标签**，改用符号翻转/随机化检验

> **v1 的问题**：v1 §8.3 写"在锚内随机交换条件标签，保持配对结构"。这**隐含假设四条件标签可交换**，
> 而 `00/10/01/11` 是**结构性、角色固定**的处理（§5），交换标签会破坏析因对比的含义
> （如把 `10` 与 `01` 互换就改变了"哪个因子"）。**本版明令禁止该做法。**

**替代方案（PROPOSED）——锚级配对符号翻转（sign-flip / randomization）检验**：

- 对某对比 `k`，令 anchor 级配对数 `D_a^k`（`a = 1..n`）。
- **锐零假设 H₀^{sharp}**："干预 `k` 对**任一** anchor 无效应" ⇒ 在 H₀ 下每个 `D_a^k` 关于 0 **对称**。
- **检验统计量** `T = mean_a D_a^k`；**随机化分布**：对每个 anchor 独立取符号 `ε_a ∈ {±1}`
  （各 1/2），生成 `T* = mean_a ε_a D_a^k`，重复至穷尽或预注册次数 `B`。
- **有效性依据（v2 修正：删除 v1 的不足论证）**：v1 曾写"正当性来自**扰动随机化 P1–P4**：
  在锐零下，扰动抽样的随机性是配对数符号对称的来源"。**该论证不充分，本版撤回**，理由：
  P1–P4 是**同一抽签在四条件间共享**（配对所需），且**扰动分布未知**、**条件标签与扰动抽样耦合**；
  由此**不能**推出"锐零下 `D_a` 关于 0 对称"。sign-flip / max-T 的**名义有效性**需要
  **明确且可证（或人工签字接受）的抽样假设**，至少满足下列之一：

  | 条件 | 内容 | V02 现状 |
  |---|---|---|
  | **A** | 干预分配在锚内**可随机重排**（随机化实验） | **不满足**：四条件结构性、非随机分配（§5） |
  | **B** | 锚从某总体**随机抽取**，且锐零下 `D_a` 对 0 对称 | **不满足**：锚由确定性 SHA-256 拒绝流生成 |
  | **C** | 存在**可交换且零下符号等概率**的重复/扰动机制，且其分布**已知** | **未证明**：P1–P4 分布未知、条件耦合（见上） |

- **默认裁定（PROPOSED）**：在 A/B/C 之一**被证明或被人工签字接受**之前，
  V02 的**确证性检验一律标记 `PENDING`**（记号 `PENDING_UNTIL_SAMPLING_ASSUMPTION_FROZEN`），
  **只报告锚级估计与区间（§8.2）**，**不报告任何 p 值**。仅当冻结文件中存在显式的
  `SamplingAssumption{unit="anchor", basis∈{A,B,C}, justification_ref=…, status="FROZEN"}` 且被人工接受时，
  才**允许**启用 sign-flip / max-T，并在报告中**引用该假设**。此门控在代码中**强制**
  （`v02lab/stats_anchor.py`：缺假设即返回 `PENDING`，不产出 p 值）。
- **交互检验的零**：对 `I_lin`，锐零 = **精确可加性**（`M11−M10−M01+M00 = 0` 对每个 anchor），
  而非"无效应"；在此零下 anchor 级交互量符号对称 ⇒ 同样用符号翻转。**须显式说明**
  交互检验的零假设是**可加性**，不是"两因素都无效"。

### 8.3.1 假设不成立时的默认路径：锚级估计 + 区间（显式抽样假设）

- 默认路径**不做确证性检验**，只给：
  - **anchor 级配对数均值**（点估计）；
  - **锚级 cluster bootstrap 区间**（§8.2；其有效性只依赖"anchor 为抽样单元"，**不依赖** A/B/C）；
  - 结果对象须携带**显式抽样假设字段**（`unit="anchor"`、`basis="UNPROVEN"|A|B|C`、`justification_ref`），
    **不得**以任意默认值冒充科研决断。
- 若人工后续**拒绝**任何抽样假设：V02 定位为**估计性研究**（§8.6 退路），永久标注
  "区间为描述性、不做频率推断"。

### 8.4 多重性与主族

- **预注册主族** = `{H-R1a, H-R1b, H-R1c, H-I-lin}`（4 个方向/双侧对比）；
  `H-I-log` 与 B1、H2 为**非主族**（分别作次要/探索，不并入主族校正）。
- **控制 FWER**：采用**最大统计量随机化**（对每个重抽样取主族内 `|T*|` 的最大值），
  以同一批符号翻转构造 FWER 受控的临界值（**尊重对比间相关**，优于 Bonferroni）。
  备选：对符号翻转 p 值用 **Holm**（小样本下更保守）。
- 每个终点**只检验一次**预注册方向；**不复用** pilot 的探索方向（§13）。

### 8.5 零事件与低事件率

- 若 B1（碰撞）事件数为 0：**只报告计数**，**不**套用 rule of three 的"<3/n"量级宣称
  （该式要求 iid Bernoulli，pilot 已证不满足；评审 §2.3/R1）。
- 如需单侧频率上界，只能在**满足独立性假设的层级**上给出并显式标注假设；否则以
  "未观测到事件"描述，不作频率推断。

### 8.6 预注册与事后选择的防护

- 终点、尺度、方向、阈值 `τ`/`τ_cap`/`η`、Δg/Δv、扰动分布、样本量、主族与多重性
  **全部在冻结文件中固定**；任何偏离进入 `DECISION_LOG` 作为显式修正（不静默）。
- **保守退路**：若审查者判定主指标变更/设计的事后选择风险不可接受（§13），则
  **只做估计与区间、不做假设检验**，并明确标注为估计性研究。

### 8.7 估计目标区分：**总体 anchor 效应 ≠ 提名后 audit 效应**（v2 新增）

> v1 把"审计流上的效应"与"总体干预效应"含混处理。二者是**不同的估计目标（estimand）**，
> **不得混同**。

- **`E_pop`（总体 anchor 效应）**：在**从总体抽取的锚**上的平均干预效应（`Δgap/Δspeed/Δboth/I_lin`）。
  这是 H-R / H-I 的目标估计量。
- **`E_audit`（提名后 audit 效应）**：在**经 discovery 提名筛选后的锚集 `π`** 上的平均效应。
  由于 `π` 是**选择性**子集（由某方法提名规则挑出），一般 **`E_audit ≠ E_pop`**，差异即**选择偏倚**。
  audit 统计量回答"**被提名的锚在被审计时表现如何**"，**不是**"干预对总体的效应"。
- **归属**：H2（方法比较）作用于 `E_audit`；H-R/H-I 作用于 `E_pop`。**禁止**用 audit 流估计总体效应，
  **禁止**把两流合并作单一估计。
- **独立总体抽样 / 确认集方案（PROPOSED，二选一）**：
  - **POP-1（独立总体样本）**：另设一条**独立锚抽样流**（新 `stream` 标签，种子与 discovery/audit
    严格分离），抽取 `n_pop` 个**未经任何提名筛选**的锚，在其上做四条件配对 → 估计 `E_pop`；
    该流**不**参与提名、**不**受方法选择影响。
  - **POP-2（确认集 confirmation set）**：V02 设计冻结后，用**全新 master seed** 抽取**独立确认锚集**，
    仅用于 `E_pop` 的确证性估计；discovery/audit 数据**不得**并入确认集。
- **门控一致性**：无论 POP-1 / POP-2，`E_pop` 的确证性检验仍受 §8.3 的 `PENDING` 门控约束
  （抽样假设未决前只报估计与区间）。

## 12. 与 CornerCaseLab v0.3.0 的**贡献重叠检查**（PROPOSED；需人工核验）

## 13. 设计的事后性披露与事后选择风险控制（PROPOSED）

### 13.1 显式披露（诚实性）

**本 V02 设计的整体构思，确实受 V01 pilot 探索性结果启发**，具体为：

1. V01 pilot 观察到的 **零碰撞**（主指标零方差）→ 促使改用**连续安全裕度**为主终点；
2. V01 pilot 探索性分析观察到的**负 ΔTTC(both)** → 提示"安全反转"值得作为假设；
3. V01 **种子语义退化**（repetition 不重采样 ego–lead）→ 促使引入**锚内随机扰动 P1–P4**。

> **含义**：V01 pilot **不是** V02 的独立确认集；以上是典型的**数据依赖（post-hoc）设计**。
> 本设计**不隐瞒**这一点。

### 13.2 事后选择风险的控制措施（PROPOSED）

1. **防火墙**：V01 数据在 V02 中**只作管道验证**，**永不**作 V02 证据、**永不**与 V02 数据合并。
2. **先验冻结**：终点、尺度、阈值、方向、扰动分布、样本量、主族与多重性**全部在任何 V02 数据前冻结**
   （冻结文件 + 指纹）。
3. **新协议、新种子、新锚**：V02 用**新 protocol id**、**全新 master seed**；V02 锚**不复用**
   V01 锚作为 V02 锚（管道验证可用 V01 记录，但**不入** V02 统计）。
4. **方向来自机制而非 pilot 符号**：反转假设的**先验方向**由机制推导（间距增大→更安全），
   **不**取自 pilot 观测到的负号；pilot 的负号只提示"值得检验"，**不**构成方向的正当性。
5. **技术 pilot 只作设计**：TP 结果只用于估计方差/验证门槛，**不**作 V02 证据；
   TP 本身也是数据依赖，须在报告中标注。
6. **透明报告**：任何 V02 报告**必须**声明"设计由 V01 探索结果启发"（本节的引用）。
7. **可选加强（若审查者要求）**：**只作估计、不作确证性检验**（§8.6）；或在其后另设
   **独立预注册确认**（新数据、新种子），本提案暂不设。

### 13.3 与 §3.7 / §8.6 的一致性

§3.7（终点选择正当性）、§8.6（预注册防护）与本节共同构成**事后选择风险的完整处置闭环**。
