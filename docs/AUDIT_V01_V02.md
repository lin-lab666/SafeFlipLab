## 第二部分：零碰撞根因分析（阶段 2）

### 2.1 仿真随机性到底随机化了什么

链路（全部有代码与数据证据）：

1. `evaluate()` 调用 `env.reset(seed=sim_seed)`；
2. `ParameterisedMerge._make_vehicles()` 构造 ego / lead / ramp 后调用 `lead.randomize_behavior()`
   与 `ramp.randomize_behavior()`；
3. `sim_seed` 的**唯一作用**是把 IDM 指数 `DELTA` 随机化到 `[3.5, 4.5]`；
4. lead 以 `speed = target_speed = front_speed` 起步且前方无车 ⇒ IDM 自由流项
   `COMFORT_ACC_MAX·(1 − (v/v₀)^DELTA)` 在 `v = v₀` 时**对任意 DELTA 恒为 0** ⇒ **lead 轨迹与种子无关**；
5. ego 由**确定性** `boundary` 控制器驱动（gap 6.0 m / headway 0.30 s / TTC 0.90 s）；
6. 因此 ego–lead 闭环节点与种子无关；ramp 车是轨迹差异的**唯一**来源，但它的影响严格**晚于**
   已观测到的 min-TTC 时刻。

**结论**：V01 中「新鲜种子」并不重采样 ego–lead 交互，所以 repetition 与 audit 对
碰撞 / TTC 终点**不提供独立信息**。

### 2.2 为什么碰撞率接近 0

- `boundary` 控制器在 `gap < 6.0 + 0.30·vx`（vx≈28 m/s 时 ≈ 14.4 m）**或** `gap/closing < 0.90 s`
  时主动制动 ⇒ 它**以设计方式维持**安全间距；
- V01 干预幅度温和（+2.0 m 间距、−1.0 m/s 初速），不足以越过该控制律；
- 25 s 时域内 min-TTC 出现在 t ≈ 1.2–9.2 s，全程 gap 保持 7.1–11.7 m、闭合速度 7.8–8.8 m/s，
  **远未闭合**。

**结论**：零碰撞是**场景域 + 控制器 + 干预幅度**共同决定的**结构性性质**，不是仿真故障，
也不是数据错误。

### 2.3 连续安全指标的适用性分析

| 问题 | 结论 |
|---|---|
| TTC 在原场景中是否有方差？ | **有**。V01 pilot 的 min-TTC 分布在 ~0.98–1.50 s，且随条件改变（ΔTTC 0.02–0.35 s） |
| TTC 是否受种子影响？ | **不受**（见 2.1）⇒ 需要**改变初始条件**才能让 repetition 携带信息 |
| TTC 是否可直接当作「风险」？ | **不能**。它是 5 Hz 采样、常速假设、仅纵向的诊断代理量，`None ≠ 安全` |
| 用 TTC 做主终点是否事后选择？ | **是**，但可通过预注册 + 独立确认缓解（见 D36） |

## 第三部分：V02 设计的科学论证（阶段 3）

### 3.1 针对 V01 三处缺陷的对应修正

| V01 缺陷 | V02 修正 | 验证方式 |
|---|---|---|
| 主终点零方差 | 改用连续 min-TTC（D29） | G3a：锚内方差 > 0 |
| repetition 无独立信息 | **锚内共享扰动**（D31）：四条件共享一次抽样，不同 repetition 抽样不同 | G4：min-TTC 跨 repetition **不再**逐位相同 |
| 度量不可核验 | 逐 step 从 trajectory 重算 + 与上游对拍（D32） | `metric_equivalence`：最大差 4.40e-6 s |

### 3.2 为什么这是「修好设计」而不是「挑好结果」

1. **方向来自机制**：更大间距、更低初速直觉上更安全（`Δ > 0`）；V02 检验的是
   「**是否**出现反直觉方向」，而**不是**沿用 V01 观测到的负号来设定方向；
2. **全部参数在 V02 任何真实数据之前冻结**（`v02_frozen_v1.json`，FROZEN，SHA-256 指纹）；
3. **不产出 p 值**（D35）⇒ 不存在「挑显著性检验」的空间；
4. **不做方法择优**：两方法等预算、同 discovery 数据、独立审计；
5. **负结果同样报告**：V02 smoke 未观察到反转，照实写。

### 3.3 明确的科学局限（不得省略）

1. **单 dev 主种子**（`2279189195`），无跨种子稳定性证据；
2. **18 个锚**是小样本；锚级区间是**描述性**的（锚非随机抽样）；
3. **域被收窄**到接近式区间，结论不外推；
4. **TTC 是代理量**，不是碰撞概率；报告不得表述为道路风险；
5. **二元端点仍近似零事件**，只作描述性计数；
6. **无 p 值、无显著性结论**；V02 是**估计性**研究；
7. **事后性**：设计受 V01 pilot 启发（D36）；
8. 未实现提案中的 P3（lead 主动减速），未实现「lead 初速 ≠ 目标速」；
9. 与 CornerCaseLab v0.3.0 在「方法比较 / 独立审计 / 等预算配对」上**高度重叠**，
   不构成新颖点；候选新增点仅「四条件反事实干预 / 安全反转作为显式估计量 /
   尺度显式交互」。
